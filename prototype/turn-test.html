Cloudflare TURN Connectivity Test

Log in as an Auth0-authorized recording host, obtain short-lived ICE credentials, and test WebRTC DataChannel communication using TURN relay candidates only. This test does not use a microphone or camera.

1. Get Short-Lived Credentials from the Authenticated Worker

The Worker obtains credentials from Cloudflare Realtime. Cloudflare API tokens and TURN key secrets are never sent to this page.

2. Test Results

Log in with Auth0 to start the test.

Short-lived credentials are not stored persistently or displayed in the log.

What This Test Verifies

  • Retrieval of relay candidates from Cloudflare TURN
  • ICE connectivity and DataChannel round-trip communication using relay candidates only
  • Verification that the selected ICE candidate pair uses relay

This test runs within the same browser. Verify signaling between separate devices, audio calls, and connectivity across different networks separately using a real PerfectPodcast call. Open this page over HTTPS or localhost.
