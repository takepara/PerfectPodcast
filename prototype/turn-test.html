Cloudflare TURN 通信テスト

Auth0で許可された収録ホストとしてログインし、短命のICE資格を取得してTURN relay候補に限定したWebRTC DataChannel通信を確認します。マイクやカメラは使用しません。

1. 認証済みWorkerから短命資格を取得

資格はWorkerがCloudflare Realtimeから取得します。Cloudflare API tokenやTURN keyの秘密値はこのページへ渡りません。

2. テスト結果

Auth0でログインしてテストを開始してください。

短命資格は永続保存せず、値をログに表示しません。

このテストで確認すること

  • Cloudflare TURNでrelay候補を取得できること
  • relay候補だけを使ったICE接続とDataChannelの往復通信
  • 選択されたICE候補ペアがrelayであること

同じブラウザー内の試験です。異なる端末間のシグナリング、音声通話、各ネットワークでの接続性は、PerfectPodcastの実通話でも別途確認してください。HTTPSまたはlocalhostで開いてください。
